# EAOS Data Architecture Package (`data/`)

## Business Capability
Enterprise Data Architecture, Data Governance (DAMA-DMBOK2), PII Redaction, Data Lineage Tracking, Data Mesh Schemas, and Data Quality Auditing.

## Package Structure
- `governance/`: Data Governance & PII Classification (`data_governance.py`).
- `lineage/`: Data Lineage & Pipeline Tracking (`data_lineage.py`).
- `models/`: Data Lake & Vector Schema Definitions (`data_models.py`).
- `quality/`: Data Quality Auditing (`data_quality.py`).
- `data_architecture.py`: Master Data Architecture Engine.
